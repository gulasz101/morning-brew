Michael Tunnell (Framework's Linux marketing guy, 15+ years on Linux) makes the pitch for leaving macOS. The core argument: MacBooks are good hardware with good trackpads and battery, and macOS gives devs a Unix-y environment without being their own IT department — but it's a **walled garden, and it's Apple's garden, not yours**. The pitch: keep the garden, take down the walls. The FW 13 Pro is positioned as the "ultimate portable developer machine" — ground-up redesign of the 13, Intel Core Ultra Series 3, 74Wh battery, LPDDR5 memory, full CNC aluminum chassis, 13.5" 3:2 touchscreen, haptic touchpad, and Ubuntu preloaded. It's their first **Ubuntu-certified** system.

**Verdict:** It's marketing, but the walled-garden framing is the honest core of the Mac→Linux argument. If you're already a Linux dev, this is preaching to the choir; if you're a Mac dev considering the jump, the FW 13 Pro is the hardware that makes it painless.

## 17. Modular: Mojo🔥 is now open source! — by share.google

![share.google](https://share.google/favicon.ico)
- **Source:** https://share.google/6IWl24BumEgxxBz7D
- **Karakeep doc:** `prqot44t17djvi9yi8h4w170`

Big one. **Mojo is now fully open source** under **Apache 2.0 with LLVM exceptions**. The compiler, tooling, and everything needed to build the language are in the `modular/modular` GitHub repo. Mojo hit **1.0 last week** (source stability), and now the whole compiler + toolchain is open.

Build from source: `git clone https://github.com/modular/modular.git`, then `./bazelw run --config=build-mojo KGEN:mojo -- run hello.mojo`. Bazel manages the build; `--config=prebuilt-mojo` pulls the latest nightly binary instead of compiling from scratch. Tests: `./bazelw test --config=build-mojo mojo/stdlib/test/...`.

**Caveat:** They're **not yet accepting contributions to the compiler/tooling** — the standard library has taken contributions since 2024, but compiler contributions open up "by the end of this year." So it's open-source *code*, but not yet open-*governance* for the core.

**Verdict:** Genuinely significant — a closed compiler for a language pitched as the "Python for AI accelerators" finally goes Apache 2.0. The LLVM exceptions matter for distributing compiled binaries. The "open source but not open to contributions yet" is the honest asterisk.
